# VECTRA

Веб-сервис для сборки редактируемых векторных композиций из готовой SVG-библиотеки. Приложение не генерирует и не дорисовывает объекты: оно только выбирает, размещает, поворачивает, масштабирует, дублирует, перекрашивает и упорядочивает загруженные SVG.

## Запуск

Проект не требует сборки и внешних зависимостей. Откройте `dist/index.html` в браузере или запустите любой локальный статический сервер из каталога `dist`.

## Возможности

- массовая загрузка отдельных SVG-файлов;
- безопасная очистка исполняемых элементов без растеризации геометрии;
- два сценария: подбор по метафоре/заголовку и сборка по точным названиям;
- четыре схемы автоматической компоновки;
- ручное перемещение, поворот, масштаб, дублирование и удаление;
- управление порядком слоёв;
- форматы 1:1, 16:9 и 9:16;
- готовые и загружаемые JSON/TXT-палитры;
- экспорт в редактируемый SVG с отдельными именованными группами объектов.

## Архитектура

`index.html` содержит оболочку редактора, `styles.css` — адаптивную визуальную систему, `app.js` — библиотеку объектов, семантический подбор, раскладку, редактор сцены, управление палитрой и экспорт.

Каждый импортированный объект хранится как запись `{id, name, category, tags, viewBox, markup}`. Исходная SVG-разметка остаётся векторной и помещается на сцену как вложенный `<svg>` внутри отдельной группы `<g>`. Трансформации задаются на уровне группы, поэтому контуры объекта не переписываются. При экспорте каждый экземпляр сохраняется самостоятельной именованной группой с `data-source-asset`, что позволяет продолжить редактирование в Figma, Illustrator или другом SVG-редакторе.

Перед добавлением в библиотеку удаляются только потенциально исполняемые узлы (`script`, `foreignObject`, внешние ссылки и обработчики событий). Это защита от выполнения кода внутри загруженного SVG; геометрические узлы не преобразуются.

Подбор по метафоре работает локально и детерминированно: текст нормализуется, ключевые слова и смысловые основы сопоставляются с названиями и тегами объектов. В runtime нет генератора изображений и нет отправки SVG на внешний AI-сервис.

## Палитра

Перекраска выполняется заменой значений `fill` и `stroke` по стабильной карте исходных цветов. Геометрия, viewBox, соотношение сторон и порядок путей не меняются. Формат JSON: `{"colors":["#DCD5FF","#7D66D9","#F5E99D","#F29B86"]}`. TXT может содержать HEX-цвета в любом порядке.

## AI-инструменты

- OpenAI Codex — проектирование архитектуры, реализация интерфейса и логики, проверка сценариев.
- Локальный семантический классификатор на основе словаря — анализ метафоры во время работы сервиса; он не генерирует графику.

## Исходные иллюстрации

Встроенная демо-библиотека отключена. При запуске библиотека пуста; для создания композиции импортируйте только SVG-элементы из предоставленных исходных иллюстраций. Скриншоты служат справочными материалами, но не заменяют SVG.

Папки `main-objects/` и `background objects/` содержат подготовленные SVG для импорта. Полноту соответствия всем 20 исходным иллюстрациям необходимо проверить отдельно. После импорта доступны оба сценария композиции и векторный экспорт. Прежние три примера из отдельной демо-библиотеки удалены как не подтверждающие соблюдение ключевого ограничения.


## Онлайн-демонстрация

После включения GitHub Pages в Settings → Pages (Deploy from a branch, `main`, `/(root)`) редактор доступен по адресу: https://qwastee.github.io/VECTRA_TEST/

Для локального запуска откройте `index.html` в браузере. Исходная копия приложения также находится в `dist/`. Перед сборкой композиции импортируйте оригинальные SVG-файлы через интерфейс редактора.
